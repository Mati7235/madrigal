# Icons

Lucide (ISC license, `crates/madrigal-ui/ui/icons/LICENSE`): 24px grid, 2px stroke, round caps and joins. The files are single-ink with stroke `#000000`; tint them with the control's content colour (Slint `Image.colorize`; on the web inline the SVG and set its stroke to `currentColor`). Sizes: 20px in buttons, 24px in menu rows, 18px in the search bar, 14px for the chip check. `*-filled` variants mark the toggled-on state. `music-2` is the missing-artwork fallback.
