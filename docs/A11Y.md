# Madrigal UI — Accessibility audit (Slint) vs the QML oracle

Read-only audit. No repo files changed, no build run.

Scope: all `.slint` under `crates/madrigal-ui/ui/` (33 files, 7699 lines), `crates/madrigal-ui/src/shell.rs`,
plus the oracle in the Python oracle's `ui/qml/`.

Baseline facts used below (Slint 1.19):

- Only `FocusScope` and `TextInput` are focusable; there is no `focusable` property on `Rectangle`
  (`i-slint-compiler-1.19.0/passes/focus_handling.rs:206`). Everything else is keyboard-unreachable
  unless wrapped in a `FocusScope`.
- `Text` auto-gets `accessible-role: text` + `accessible-label` = its text; `TextInput` auto-gets
  `text-input` + `accessible-value`; `Image` auto-gets `image`
  (`i-slint-compiler-1.19.0/passes/lower_accessibility.rs:63-115`). Decorative icons/text therefore
  create noise unless silenced.
- `accessible-*` props are rejected unless `accessible-role` is set on the same element
  (`lower_accessibility.rs:47-61`). Roles used here (`content-info`, `region`) are valid landmarks
  (`i-slint-common-1.19.0/enums.rs:519-536`). `accessible-action-default/-increment/-decrement/
  -set-value/-expand` callbacks exist (`i-slint-compiler-1.19.0/typeregister.rs:380-385`).
- Repo-wide grep: `focus()` = 0 occurrences, `FocusScope` = 1 (SearchPage), `key-pressed` = 2,
  `accessible-action-*` = 0.

## 2. Critical gaps

1. **Keyboard is a dead end (blocker).** Every action in the product is a `TouchArea`
   (`components/buttons.slint:63,111`, `cards.slint:56,113`, `rows.slint:92`,
   `selection.slint:40,85,157`, 56 instances in total). There are zero `focus()` calls and the only
   `FocusScope` is `pages/catalog/search.slint:9`, whose `focus-requested` is only used to draw a ring
   (`search.slint:70`). Tab therefore reaches only the six `TextInput`s
   (`fields.slint:49,114`, `overlays.slint:138`, `library.slint:769`, `section.slint:63`,
   `onboarding.slint:159`). `M3Button.focus-visible` (`buttons.slint:8`) is never bound, so
   `focus-ring` (`:31-37`) never paints. Esc "focuses the sidebar" (`shell.slint:450`) but
   `SideNav` has no key handler at all (`sidebar.slint:39-194`): focus lands nowhere.

2. **24 icon-only buttons ship with no accessible name.** `M3IconButton`
   (`buttons.slint:70-82`) has no label property, so `accessible-label` is absent at every call site:
   `bar.slint:94,102,112,121,133`; `full.slint:98,125,133,251,261,269,279,287,355,365,373,381`;
   `queue.slint:44,53,167`; `lyrics.slint:37`; `detail.slint:42`; `settings/section.slint:208,216`.
   Play/pause/next/like are indistinguishable to a screen reader.

3. **State is never exposed on sliders and toggles.** `M3Slider` sets role `slider` but no
   `accessible-value` (`selection.slint:105-106`); `M3Switch`/`M3Checkbox` set role but no
   `accessible-checked` (`:16-17`, `:60-61`); no `accessible-action-*` anywhere. EQ/tempo/volume
   (`dialogs.slint:152,168,281`, `settings/section.slint:75`) read as valueless sliders; settings
   switches never report on/off.

4. **Overlays are not dialogs and do not trap or restore focus.** Confirm/Prompt declare
   `accessible-role: text` (`overlays.slint:11,106`) instead of `dialog`; no initial focus, no Tab
   cycle, no focus restore (oracle: `OverlayFocusController.qml:11-66`,
   `ConfirmOverlay.qml:18-47`). The Library sort and tags popovers (`library.slint:684,738`) are not
   modal, have no role, and are **not in the Esc chain** (`shell.slint:420-452`), so Esc cannot close
   them.

5. **Rows and cards lose their identity.** Library song rows (`library.slint:312`), queue rows
   (`queue.slint:115`), download rows (`downloads.slint:87,197`), history rows
   (`library.slint:491`), lyric lines (`lyrics.slint:106`) and dialog option rows
   (`dialogs.slint:52`, `library.slint:729`) have no role and no label. `QueueDrawer`/`LyricsView`
   announce a `list` with zero `list-item` children. `M3Card` labels only `title`
   (`cards.slint:14`), dropping `subtitle` (oracle: `MediaCard.qml:15` concatenates both).

6. **Wrong labels.** Year-prev announces `action.back` (`library.slint:562`); year-next announces
   `action.play` (`library.slint:588`).

7. **`/` does not focus the search field.** `shell.slint:488-492` sets `search-focused`, forwarded to
   `SearchPage.focus-requested` (`pagehost.slint:175`) which only sets `ring` (`search.slint:70`);
   no `focus()` and no select-all. Oracle does `forceActiveFocus()` + `selectAll()`
   (`Main.qml:271-286`).

8. **No production keyboard path, and no typing guard.** `dispatch_key` is called only from checks
   (`check_ui_shell.rs:95`, `check_ui_catalog.rs:391`, `check_ui_player.rs:162`); `crates/madrigal-app`
   has no key handler and `MainShell` is never instantiated. `handle-key` guards only overlays
   (`shell.slint:453`), so once wired, typing `n`, `p`, Space, `[`/`]` in any text field would trigger
   playback/page changes. Oracle blocks with `mainShortcutsBlocked` (`Main.qml:37`).

9. **Landmark roles are misused.** Page containers declare `accessible-role: text`
   (`home.slint:25`, `explore.slint:22`, `library.slint:65`, `downloads.slint:18`,
   `pagehost.slint:152`, `detail.slint:27`), wrapping interactive trees in a static-text node; no
   `main`/`navigation`/`search`/`complementary` landmarks are used even though Slint supports them.

10. **Double nodes everywhere.** Each button/card/row contains `Text` children that auto-emit
    `role: text` (`buttons.slint:48`, `cards.slint:40,103`, `rows.slint:44,52`), duplicating the
    parent label. `Icon` inherits `Image` (`icons.slint:56`) and is never silenced; oracle marks icons
    `Accessible.ignored: true` (`LucideIcon.qml:16`).

11. **Labels contradict cues.** "Reorder" is announced for the chips overflow menu
    (`library.slint:96`), "move up/down" for horizontal chip moves (`:115,:134`) — semantics are
    horizontal but wording is vertical.

12. **No open-player affordance.** Oracle's bar title is a button labelled `action.openPlayer`
    (`NowPlayingBar.qml:52`); `bar.slint` exposes no such callback.

## 4. Fix plan (5 tasks, ordered)

### T1 — Accessible names for every icon-only control + silence decoration
Files: `ui/components/buttons.slint` (add `in property<string> label;`, bind
`accessible-label: root.label;` and `accessible-description` next to `:82`), `ui/components/icons.slint`
(add `accessible-role: none;` to `Icon`), call sites listed in gap 2 (24 labels, reuse existing i18n
keys: `action.playPause`, `action.nextTrack`, `action.favorite`, `action.openQueue`, `action.close`,
`action.volume`, `action.shuffle`, `action.repeat`, `action.back`, `action.moveUp/Down`).
Also fix `library.slint:562` → `library.stats.prevYear`, `:588` → `library.stats.nextYear` (add keys).
Verify: new check `crates/madrigal-ui/tests/checks/check_ui_a11y.rs` iterates
`ElementHandle::find_by_element_id(&shell, "NowPlayingBar::bar-prev")` etc. and asserts
`accessible_label().is_some()`; `find_by_accessible_label(&shell, "action.nextTrack")` yields exactly
one handle; no element reports `AccessibleRole::Image` for `Icon`.

### T2 — Expose value/checked state and AT actions on form controls
Files: `ui/components/selection.slint` — `M3Slider`: `accessible-value: root.value;
accessible-value-minimum: 0; accessible-value-maximum: 1; accessible-value-step: 0.01;
accessible-action-increment/decrement/set-value` (clamp + `changed()`); `M3Switch`/`M3Checkbox`:
`accessible-checked: root.checked; accessible-action-default` (toggle + `toggled()`). Add `label:` to
`dialogs.slint:152,168,281` (pitch/speed/band Hz) and `cards.slint:72` chips:
`accessible-checked: root.selected`.
Verify: `EqBand` handle `accessible_value()` in `[0,1]`, changes after
`invoke_accessible_increment_action()`, and `band-changed` counter increments; settings switch
`accessible_checked() == Some(true)` after `invoke_accessible_default_action()`;
`accessible_value_maximum() == Some(1.0)`.

### T3 — Keyboard focus model for buttons, chips, cards, rows, sliders
Files: `ui/components/{buttons,cards,rows,selection}.slint` — wrap each in an inner `FocusScope`
(id kept for tests) with `key-pressed`: Enter/Space → activate, arrows → `changed()`/step; bind
`focus-ring` to `has-focus` instead of the unused `focus-visible` (`buttons.slint:8,35`); give
`M3Card`/`M3Chip`/`M3ListItem` a 3px ring like the oracle (`MediaCard.qml:26`). Containers:
`shell/sidebar.slint` (roving index + Up/Down on a `FocusScope`), `player/queue.slint:110` and
`library.slint:312` (list `FocusScope`, Up/Down move a `focus-index`, Enter plays, `Delete`/`minus`
removes).
Verify: `send_key_combo(&shell, &["Tab"])` from the window then `send_keyboard_key_text("Return")`
bumps `play-toggle-count` (repo counter seam, `shell.slint:124`); Up/Down on the queue changes the
selected index property; `dispatch_key(&shell, "Escape")` remains a no-op while a `TextInput` has focus.

### T4 — Dialog semantics, focus trap, Esc chain
Files: `shell/overlays.slint:11,106` (`accessible-role: dialog;` + `accessible-modal`-equivalent via
label), inner `FocusScope` with `init => { self.focus(); }`, Tab/Shift-Tab cycle, Esc → `dismissed()`;
`player/dialogs.slint:16,124,217,316,385` same treatment; `library.slint:684,738` sort/tags popovers
get `dialog`/`list` roles + trap, and Esc branches added to `shell.slint:420-452`
(`lib-sort-open`, `lib-tags-open` before `detail-stack`). Restore focus to the invoking element on
close (store a `focus-return` int, mirroring `OverlayFocusController.qml:36-66`).
Verify: open confirm → `find_by_element_id("ConfirmOverlay").accessible_role() ==
Some(AccessibleRole::Dialog)`; send `Escape` → overlay `0` and the invoker's activation counter is
unchanged; Tab from the last button lands on the first (`accessible_label` assertion).

### T5 — Shortcut parity, `/` focus, typing guard, docs
Files: `shell/shell.slint:419-535` + `src/shell.rs:91` + `crates/madrigal-app` (add
`Window::on_key`-equivalent via a `FocusScope` root that forwards unhandled keys to `handle-key`):
track `text-input-focused` and short-circuit all non-Esc shortcuts; `/` → new
`search-focus()` that calls `search-input.focus()` and `select-all` (`fields.slint:114`); map `F` to
favorite and move the full player to `Shift+F` (or keep `F` and rebind favorite) in
`docs/UI.md:37-41`; add the missing sort/tags Esc handling (shared with T4).
Verify: set `search-query` by sending `/` + text `"n"` → `next-count` stays 0 and `search-query`
changes; `dispatch_key(&shell, "f")` toggles `like-toggled` (new counter); a doc-parity check parses
`docs/UI.md:37-41` and asserts every listed key string appears in `handle-key`.

Suggested registry row for `crates/checks.toml` + `docs/TESTING.md` registry:
`ui_a11y` / `offline` / "Labels, roles, value/checked state, focus trap and shortcut guards".

### Harness notes for the checks
`ElementHandle` exposes `accessible_role()`, `accessible_label()`, `accessible_value()`,
`accessible_value_minimum/maximum/step()`, `accessible_checked()`, `accessible_enabled()`,
`accessible_description()`, `accessible_id()`, plus `invoke_accessible_default_action()`,
`invoke_accessible_increment_action()`, `invoke_accessible_decrement_action()`
(`i-slint-backend-testing-1.19.0/search_api.rs:634-1011`). It has **no** `has_focus()` accessor, so
assert focus through the existing `@testable` counters (`shell.slint:124-131`) and through
`i_slint_backend_testing::internal_tests::send_key_combo` / `send_keyboard_key_text`
(`internal_tests.rs:50-108`). Element ids already exist for every control listed above, so no new
ids are required for T1/T2; T3/T4 add `focus-index`/`focus-return` properties only.
